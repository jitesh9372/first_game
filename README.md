# First Game

A 3D First-Person game project developed with Unity and Universal Render Pipeline (URP).

## 🚀 Features
- **Universal Render Pipeline (URP)**: Optimized graphics settings for PC and mobile platforms.
- **Enhanced Input System**: Modern input action mapping for responsive controls.
- **Sample Scene**: Pre-configured environment, lighting, and volume profiles.

## 🛠️ Tech Stack & Requirements
- **Engine**: Unity 6 / Unity 2022+ LTS
- **Render Pipeline**: Universal Render Pipeline (URP)
- **Input System**: New Unity Input System (`com.unity.inputsystem`)

## 🎮 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/jitesh9372/first_game.git
   ```
2. Open **Unity Hub**.
3. Click **Add project from disk** and select the cloned folder.
4. Open the project with your installed Unity Editor version.
5. In the Project window, navigate to `Assets/Scenes/SampleScene.unity` and press **Play**.
